## 费用怎么算

你付多少，取决于**谁按下了按钮**：是你自己，还是替你操作的 LP Agent 自动化功能。

  <Card title="自动化操作时" icon="robot">
    <div className="mt-2">

      </div>

| 操作 | 费用 |
| --- | --- |
| Copy LP 替你开仓 | 0% |
| 带单钱包平仓、减仓或领取手续费时，Copy LP 跟着替你操作 | 所收 LP 手续费收益的 8% |
| 止盈或止损触发平仓 | 所收 LP 手续费收益的 8% |
| 你添加流动性（Zap In、加仓） | 投入金额的 0.1% |
| 你移除流动性（减仓、Zap Out、平仓） | 取出金额的 0.1% |
| 复投（Compound，Solana DLMM） | 0% |
| 兑换（swap） | 0% |
| [Claim SOL](/zh/features/claim-sol) | 0% |
| 充值和提现 | 0% |

收费规则看的是这次操作，而不是仓位当初怎么开的。你自己开的仓位，如果被你设的止损平掉，要付其 LP 手续费收益的 8%。跟单开的仓位，如果你自己手动平仓，付 0.1%。

**示例（自动化）**：一个跟单仓位赚了 1 SOL 的 LP 手续费收益。带单钱包退出、你的跟单仓位随之平仓时，LP Agent 收取 0.08 SOL。如果这个仓位没赚到手续费，你什么都不用付。

**示例（手动）**：你在池子页面 Zap In 了 10 SOL。LP Agent 收取 0.01 SOL。
