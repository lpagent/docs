## 登录

点击顶部栏的 **Connect Wallet**（连接钱包）。你可以用以下方式登录：

| 方式 | 怎么用 |
| --- | --- |
| **钱包插件**（Phantom、Solflare、MetaMask、Rabby 等） | 选择你的钱包，批准一条登录签名消息。不发交易，不花 Gas。你上次用过的钱包排在最上面。 |
| **WalletConnect**（电脑端） | 用手机钱包扫二维码，批准连接，再批准登录签名消息。 |
| **手机** | 从列表里选你的钱包，或者搜索。有些钱包会在自己的浏览器里打开 LP Agent。如果列表里没有你的钱包，就在钱包自带的浏览器里打开 LP Agent，然后从那里连接。 |
| **邮箱** | 输入邮箱，再填入收到的 6 位验证码。验证码由我们的钱包服务商 Turnkey 发送，几分钟后失效。不支持带 `+` 的邮箱地址。 |

在钱包弹出签名请求之前，会先跑一个快速的浏览器检查。一般会自动通过。

<Note>
  请始终用你注册时的钱包或邮箱登录。代理钱包不是登录钱包：如果你把它导入 Phantom 或其他钱包，再用它登录，LP Agent 会为它开一个全新的、独立的账户，里面是一个空的代理钱包。你的仓位和资金仍然在原来的账户里。
</Note>

### 一个账户对应一个网络

你的账户绑定一个网络：

- 用 **Solana** 钱包登录，玩 Meteora DLMM 和 DAMM v2 池子。
- 用 **EVM** 钱包（0x 地址）登录，玩 Robinhood Chain 上的 Uniswap V3 和 V4 池子。
- 新的**邮箱**账户会让你选一次 **Solana** 或 **Robinhood**。

你仍然可以浏览另一个网络上的池子和钱包，但只能在你账户所属的网络上开仓或跟单。

### 钱包升级前创建的账户

LP Agent 在 2026 年 9 月迁移到了新的钱包基础设施。大多数老账户都已经迁移过来，并且**保留了原来的代理钱包地址**：照常连接你一直在用的那个钱包就行。

旧的登录方式已经从应用里移除。如果你的浏览器还停留在旧的登录状态，应用会让你退出一次。重新连接钱包即可继续使用。

如果你的钱包或邮箱所属的账户还没有迁移，登录时应用会提示你。请在我们的 [Discord](https://discord.gg/lpagent) 开工单，团队会帮你恢复访问。

### 登录会话

使用应用期间你会一直保持登录，最长 7 天。如果超过一天没有打开应用，就需要重新登录。点击账户面板里的 **Disconnect**（断开连接），就会在这台设备上退出登录。

## 你的代理钱包

每个账户都有一个**代理钱包**（agent wallet），在应用里显示为 **Embedded Wallet**（内置钱包）。LP Agent 用这个钱包开仓、跟单和平仓，所以你不用每笔交易都签名。

- 它和你的登录钱包是分开的。
- 钱由你充进去，你随时可以提现。
- 你可以导出它的私钥，导入到任何钱包。
- 自动化功能只能用它做 LP 操作和兑换（swap）。详见[安全](/zh/security)。

点击顶部栏里你的地址，就能打开账户面板。

## 账户面板

<Frame>
  ![账户面板](/images/app/rh-account-panel.png)
  <em>账户面板：你的代理钱包、Deposit、Withdraw、Settings 和你的资产</em>
</Frame>

面板上显示：

- **Signed in with**（登录钱包）：你用来登录的钱包，仅在它不是代理钱包时显示。
- **Embedded Wallet**：你的代理钱包地址，带复制按钮。
- **Deposit**（充值）、**Withdraw**（提现）和 **Settings**（设置）。
- **Finish setup**（完成设置）：你还没完成的设置步骤。全部完成后就不再显示。详见下方“完成设置”。
- **Reports**（反馈记录）：你最近的三条反馈及其进度，可以点 **See all**（查看全部）。详见下方“反馈记录”。
- **Assets**（资产）：你的代币及其价值，以及按美元和 SOL 或 ETH 计算的总额。低于 $1 的小额余额会折叠在 **Show all** 后面。点一下代币就能兑换它。
- **Get API Key**、**Docs**、**Language**（语言）、**Disconnect**，以及我们的 Discord 和 X 链接。

面板里有需要你查看的内容时，顶部栏的钱包按钮上会出现一个**黄点**：可能是还没完成的设置步骤，也可能是你的反馈有了新进度。LP Agent 不会为这些弹窗打扰你。

<Note>
  升级前创建、且从未授权过的账户，看到的是 **Grant full access**（授予完整权限），而不是 Deposit 和 Withdraw。授权后就会创建代理钱包。
</Note>

### 完成设置

| 项目 | 作用 |
| --- | --- |
| **Meteora referral code**（Meteora 推荐码） | 仅限 Solana 的新代理钱包。在显示的时间之前，选好你的钱包加入哪个 Meteora 推荐码。不选的话，LP Agent 会关联自己的推荐码 LPAGENT。详见 [Meteora 推荐奖励](/zh/referral)。 |
| **Link Discord**（联系方式） | 打开 **Settings > Account** 里的 Discord 一行。详见下方“关联 Discord 和微信”。 |

### 语言

应用支持 English 和中文（简体）。第一次打开时会跟随浏览器的语言。想切换的话，在账户面板里用 **Language**（语言）选择 EN 或 中文。你的选择会保存在当前浏览器里。

## 关联 Discord 和微信

进入 **Settings > Account**，在 **Discord** 一行点 **Connect**（连接）。Discord 会请你授权 LP Agent，然后跳回应用。之后这一行会显示 **Connected as @你的用户名**（已连接）。点 **Unlink**（断开）可以取消关联。

为什么要关联：

- 你在我们的 [Discord](https://discord.gg/lpagent) 开工单时，客服能马上认出你，直接查看你的仓位。
- 你在 Discord 开的工单也会出现在你的 **Reports**（反馈记录）里，和你在应用里提交的反馈放在一起。

关联之后，你不会因此收到任何消息。客服会在你自己开的工单里和你沟通。

应用切换到中文时，同一个标签页里还有一个 **WeChat ID**（微信号）输入框。填好后点 **Save**（保存）。只有 LP Agent 团队能看到它。填了 Discord 或微信号中的任意一个，完成设置里的这一项就会消失。

## 反馈记录

仓位看起来不对？在 Portfolio、仓位详情或者池子的仓位列表里，点仓位上的 **Report**（反馈），描述一下问题，再点 **Submit**（提交）。如果是跟单的问题，在 [Copy Logs](/zh/features/copy-management#copy-logs) 里点 **Something off? Report this copy**（有问题？反馈这笔跟单）：选一下哪里不对，这笔跟单的日志会自动附上。

每条反馈都有一个工单号。在账户面板的 **Reports**（反馈记录）里查看进度：

| 状态 | 含义 |
| --- | --- |
| **Sent**（已发送） | 团队已经收到你的反馈。 |
| **Checking**（处理中） | 团队正在查看。 |
| **Need more info**（需要更多信息） | 团队需要你补充信息。请在 Discord 开工单，并附上工单号。 |
| **Fixed**（已修复） | 团队已经修好了。你可能会被问到 **Is it working now?**（现在正常了吗？），选择 **All good**（没问题了）或 **Still need help**（还需要帮助）。 |
| **Closed**（已关闭） | 已结束。关闭的反馈不会再显示在面板里。 |

点开一条反馈，可以看到每一步的时间、你提交的内容，以及带 **Copy**（复制）按钮的工单号。想直接沟通，点 **Open a Discord ticket**（去 Discord 开工单）并附上工单号。

<Tip>
  不登录也可以提交反馈。反馈会保存在当前浏览器里，连接钱包后会自动转到你的账户。
</Tip>

## 充值

点击顶部栏或账户面板里的 **Deposit**。

- **From**（你的钱包名）：输入金额或点 **Max**，然后点 **Deposit** 并在钱包里确认。Max 会留下一点点余额用来付网络手续费。
- **Receive**（收款）：显示二维码和代理钱包地址。可以从任意钱包或交易所转入。只能用页面上显示的网络转账，否则资金可能丢失。

| 网络 | 充值 | 说明 |
| --- | --- | --- |
| Solana | SOL | 最低 0.001 SOL。 |
| Robinhood Chain | ETH | ETH 用来付 Gas。想用 USDG 开仓，就通过 **Receive** 充值 USDG，并在 Settings 里把 **Base Token** 设为 USDG。 |

邮箱登录的账户只有 **Receive**。应用内不支持银行卡或银行买币：请在别处买好加密货币再转进来。

## 提现

点击账户面板里的 **Withdraw**（提现）。一共三步：

1. **Select Token**（选择代币）：代理钱包里的任意代币。
2. **Destination and Amount**（目标地址和数量）：粘贴地址，或者使用你的主钱包（登录钱包）。
3. **Review and confirm**（检查并确认）：仔细核对地址。提现一旦发出就无法撤回。

提现由你自己批准：用登录钱包签名，邮箱账户则用验证码确认。LP Agent 不收提现手续费，只需支付网络手续费。

## 导出私钥

进入 **Settings > Account > Export Private Key**，点击 **Export**。

1. 你的登录钱包会让你签一次名来批准导出。邮箱账户可能需要输入验证码。
2. 点击 **Reveal private key**（显示私钥）。私钥显示在我们钱包服务商提供的安全窗口里。LP Agent 永远看不到它。
3. 把它存到安全的地方。关掉窗口后它就会消失。

<Warning>
  任何人拿到这个私钥，就能控制这个钱包和里面的所有资产。千万不要分享给别人，也不要粘贴到任何网站。
</Warning>

你可以把私钥导入 Phantom、Solflare、Backpack、MetaMask、Rabby 或同一网络的任何其他钱包。登录 LP Agent 时请继续用你原来的钱包：用导入的代理钱包登录，会开一个全新的独立账户。

## 把 LP Agent 安装成应用

LP Agent 可以作为 Web 应用安装：

- **电脑端 Chrome 或 Edge**：打开浏览器菜单，选择 **Install app**（安装应用）。
- **Android**：打开浏览器菜单，选择 **Add to Home Screen**（添加到主屏幕）或 **Install app**。
- **iPhone**：在 Safari 里点 **Share**（分享），再点 **Add to Home Screen**。iPhone 上要收推送通知，必须先这样安装。

想在仓位或跟单有变动时收到提醒，请看[通知](/zh/features/notifications)。
