## llms.txt

LP Agent 在这里提供机器可读的文档入口：

- [`https://docs.lpagent.io/llms.txt`](https://docs.lpagent.io/llms.txt)

AI 系统可以从这个文件开始，先了解文档结构，再加载更深入的页面。

## 使用方法

1. 获取 `https://docs.lpagent.io/llms.txt`
2. 解析其中列出的文档路径
3. 根据任务意图加载相关页面
4. 执行操作时，参考 [AI API 指南](/zh/ai-api-guide) 和 [CLI](/zh/cli) 里的用法
