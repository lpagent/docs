## 哪里支持什么

| 功能 | Meteora DLMM | Meteora DAMM v2 | Uniswap V3 | Uniswap V4 |
| --- | --- | --- | --- | --- |
| [Smart LP](/zh/features/smart-lp) 排行榜 | 支持 | - | 支持 | 支持 |
| [Copy LP](/zh/features/copy-lp) | 支持 | 支持 | 支持 | 支持（带 Hook 的池子需要自己开启） |
| 用单一代币 [Zap In](/zh/features/create-position)（单币入池） | 支持 | 支持 | 支持 | 支持 |
| 策略（Spot、Curve、Bid-Ask） | 支持 | - | - | - |
| [止盈 / 止损](/zh/features/take-profit-stop-loss) | 支持 | 支持 | 支持 | 支持 |
| 领取手续费 | 支持 | 支持 | 支持 | 支持 |
| 复投（Compound） | 支持 | - | - | - |
| 一键 Zap Out（一键出池） | 支持 | - | - | - |
| [资金保护](/zh/features/copy-management) | 支持 | 支持 | - | - |
| [Claim SOL](/zh/features/claim-sol) | 支持 | 支持 | - | - |
| [Open API](/zh/api-reference/introduction) | 读取数据和构建交易 | 读取数据和构建交易 | 读取数据 | 读取数据 |

## 给开发者

[LP Agent Open API](/zh/api-reference/introduction) 提供两个网络的池子、仓位和钱包数据。传 `chain=ROBINHOOD` 读取 Robinhood Chain 的数据；默认是 `SOL`。通过 API 构建 Zap In、Zap Out 和领取交易，目前在 Solana 上可用。Robinhood 的具体细节见 [Robinhood Chain 集成](/zh/integration/robinhood)。
