Robinhood Chain、BNB Chain 和 Elysium 共用一个 EVM 账户：同一个代理钱包地址在三个网络上都能用。在应用顶部的 **Chain** 菜单里选择网络。

## 给开发者

[LP Agent Open API](/zh/api-reference/introduction) 提供 Solana、Robinhood Chain 和 Elysium 的池子、仓位和钱包数据。传 `chain=ROBINHOOD` 或 `chain=ELYSIUM` 读取 EVM 数据；默认是 `SOL`。通过 API 构建 Zap In、Zap Out 和领取交易，目前在 Solana 上可用。BNB Chain 暂时还不在 Open API 里。各网络的具体细节见 [Robinhood Chain](/zh/integration/robinhood)、[BNB Chain](/zh/integration/bnb) 和 [Elysium](/zh/integration/elysium)。
