---
title: "止盈与止损"
description: "仓位涨到或跌到你选的百分比时，自动平仓"
---

止盈（TP）和止损（SL）会在仓位的盈亏（PnL）达到你设的阈值时帮你平仓。两个网络都支持，你不在线时也会一直盯着。

## 给仓位设置 TP/SL

在你的 [Portfolio](/zh/features/portfolio) 里，点某个当前仓位上的 **Settings** 标签（还没设置时显示 **Set TP** / **Set SL**）。

| 选项 | 作用 |
| --- | --- |
| **TP/SL Currency** | 用 SOL 或 USD（Solana），或者 ETH 或 USD（Robinhood Chain）来算盈亏。 |
| **Take Profit** | 仓位涨了这么多百分比时平仓。 |
| **Stop Loss** | 仓位跌了这么多百分比时平仓。 |

勾选对应的框来开启，然后按 **Save Changes**。取消勾选就关闭。

<Tip>
  币种很重要。一个 SOL/USDC 仓位可能同时按 USD 算在赚、按 SOL 算在亏。选你真正用来算收益的那个币种。
</Tip>

TP 和 SL 适用于你代理钱包（agent wallet）里的仓位。放在登录钱包里的仓位无法使用。

## 让每个新仓位都带 TP/SL：Auto TP/SL

打开 **Settings > General > Auto TP/SL**。

- 默认关闭。关闭时，你要自己给每个仓位设置 TP/SL。
- 打开后，每个**新**仓位都会用下面的默认值：
  - **Currency**（SOL/ETH 或 USD）
  - **Take Profit**：默认 10%
  - **Stop Loss**：默认 10%
- 不会改动你已经有的仓位。

<Note>
  **跟单的仓位不用 Auto TP/SL。** 它们用的是已跟单钱包的 [Exit rules](/zh/features/copy-settings)（退出规则）里的 TP/SL。谁先触发就按谁平掉跟单仓位：你的 TP/SL，或者带单钱包自己的退出。
</Note>

## 触发后会发生什么

1. LP Agent 从你的代理钱包平仓，并兑换回来（Solana 上换回 SOL；Robinhood Chain 上换回开仓时用的币种）。
2. 仓位移到 **Historical positions**（历史仓位），带上最终盈亏。
3. 如果你开了通知，会收到一条 **Take profit hit** 或 **Stop loss hit** 推送通知，附上结果。详见[通知](/zh/features/notifications)。
4. 仓位的 **Logs** 会显示每一步，比如 take profit queued 和 close success。

TP 或 SL 平仓算作自动化操作：LP Agent 从领取到的 LP 手续费收益里收 8%。详见[费用](/zh/fee)。

<Warning>
  止损能限制亏损，但保证不了成交价。行情很快的时候，平仓成交价就是交易上链那一刻的价格，而且每次平仓都要付兑换成本和网络成本。在小仓位上设太紧的止损，花掉的可能比省下的还多。
</Warning>
