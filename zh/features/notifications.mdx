LP Agent 可以给你的手机或电脑发推送通知，就算标签页关着也能收到。

## 打开通知

<Steps>
  <Step title="打开 Settings > Account">
    在账户面板里按 **Settings**，再点 **Account** 标签页。
  </Step>
  <Step title="打开 System Notifications">
    浏览器会请求权限。点允许。
  </Step>
  <Step title="启用这台设备">
    每台设备要单独订阅。如果你看到 "Notifications are on, but this device isn't receiving them yet"（通知已开启，但这台设备还没收到），按 **Enable on this device**。
  </Step>
  <Step title="测试一下">
    按 **Send test notification**。
  </Step>
</Steps>

你也可以在 **Copy LP** 页面顶部的横幅上按 **Turn on**。

## 可以收到哪些通知

打开 System Notifications 后，所有事件默认都是开的。把你不想要的关掉就行。

| 分组 | 事件 | 什么时候 |
| --- | --- | --- |
| **Auto exits** | **Take profit hit** | 你的止盈平掉了一个仓位。附带最终盈亏（PnL）。 |
| | **Stop loss hit** | 你的止损平掉了一个仓位。附带最终盈亏。 |
| **Copy trading activity** | **Position opened** | 带单钱包开仓后，你的跟单也开了仓。 |
| | **Position increased** | 跟单仓位添加了流动性。 |
| | **Position decreased** | 跟单仓位移除了流动性。 |
| | **Position closed** | 带单钱包退出了，你的跟单也跟着退出。附带最终盈亏。 |
| | **Fees claimed** | 跟单仓位领取了手续费。 |
| | **Copy failed** | 跟单没能完成，比如没 Gas、滑点或余额不足。 |
| | **Copy skipped** | 你的筛选拒绝了一次跟单，比如代币质量下限或被屏蔽的池子。 |

如果 LP Agent 因为你的代理钱包没钱而暂停了你的跟单，你也会收到推送。

## iPhone 和 iPad

iOS 只给添加到主屏幕的应用发推送通知：

1. 用 Safari 打开 [app.lpagent.io](https://app.lpagent.io)。
2. 点 **Share**（分享），再点 **Add to Home Screen**（添加到主屏幕）。
3. 从主屏幕打开 LP Agent，在那里打开通知。

## 关闭通知

关掉 **System Notifications**，或者单独关掉某些事件。按 **Disconnect** 也会移除这台设备的订阅。

## 仓位提示音

除了推送通知，打开着的应用还会播放一段很短的双音提示音：开仓时音调上升，平仓时音调下降。提示音在交易上链后播放，Solana 和 Robinhood Chain 都有：

- **开仓**：创建仓位。在 Robinhood Chain 上也包括 Zap In 和双币存入。
- **平仓**：全部平掉一个仓位，用 Zap Out（一键或者从 **Close** 表单），或者在 Robinhood Chain 上 100% 提取。

给仓位加流动性或者只提取一部分，不会有声音。

打开池子页面时，如果你的某个仓位被自动平掉（比如止盈、止损或跟单退出），你也会听到平仓提示音。浏览器可能要求你先在页面上点过一下，才允许播放这个声音。

提示音默认开启。在 **Settings > General > Position Sounds** 里可以关掉。这个选择保存在这台设备上，重新打开时会播放一次提示音，让你听听效果。
