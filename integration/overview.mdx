## What works where

| Feature | Meteora DLMM | Meteora DAMM v2 | Uniswap V3 | Uniswap V4 |
| --- | --- | --- | --- | --- |
| [Smart LP](/features/smart-lp) leaderboard | Yes | - | Yes | Yes |
| [Copy LP](/features/copy-lp) | Yes | Yes | Yes | Yes (hooked pools opt-in) |
| [Zap in](/features/create-position) from one token | Yes | Yes | Yes | Yes |
| Strategies (Spot, Curve, Bid-Ask) | Yes | - | - | - |
| [Take profit / stop loss](/features/take-profit-stop-loss) | Yes | Yes | Yes | Yes |
| Claim fees | Yes | Yes | Yes | Yes |
| Compound | Yes | - | - | - |
| One-click zap out | Yes | - | - | - |
| [Fund protection](/features/copy-management#fund-protection-solana) | Yes | Yes | - | - |
| [Claim SOL](/features/claim-sol) | Yes | Yes | - | - |
| [Open API](/api-reference/introduction) | Read and transactions | Read and transactions | Read | Read |

## For developers

The [LP Agent Open API](/api-reference/introduction) serves pool, position and wallet data for both networks. Pass `chain=ROBINHOOD` to read Robinhood Chain data; it defaults to `SOL`. Building zap-in, zap-out and claim transactions through the API is available on Solana. See [Robinhood Chain Integration](/integration/robinhood) for the Robinhood specifics.
