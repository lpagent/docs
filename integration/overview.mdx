## Supported Protocols

LP Agent runs on two chains. Pick the chain with the `chain` parameter (`SOL` or `ROBINHOOD`) wherever the API or CLI accepts one.

| Chain | Chain key | Protocols | Native token |
| --- | --- | --- | --- |
| Solana | `SOL` | Meteora DLMM, Meteora DAMM v2, Orca | SOL |
| Robinhood | `ROBINHOOD` | Uniswap v3, Uniswap v4 | ETH |
