Robinhood Chain, BNB Chain and Elysium share one EVM account: the same agent wallet address works on all three. Pick the network in the **Chain** menu at the top of the app.

## For developers

The [LP Agent Open API](/api-reference/introduction) serves pool, position and wallet data for Solana, Robinhood Chain and Elysium. Pass `chain=ROBINHOOD` or `chain=ELYSIUM` to read EVM data; it defaults to `SOL`. Building zap-in, zap-out and claim transactions through the API is available on Solana. BNB Chain is not in the Open API yet. See [Robinhood Chain](/integration/robinhood), [BNB Chain](/integration/bnb) and [Elysium](/integration/elysium) for the specifics of each network.
